Informasi XIDZs-WRT

  • Detail Sistem:XIDZs-WRT Adalah Firmware Custom Berbasis OpenWrt Dan ImmortalWrt
  • Info Firmware:23.05.x + 24.10.x ( .IPK ) | 25.12.x ( .APK )
  • Alamat Ip Default:IP: 192.168.1.1
  • Password Default:User: root | Pass: luxe
  • WIFI Jaringan:SSID: XIDZs / XIDZs_5G | Sandi: XIDZs2026
  • Saran Instalasi:Format Sdcard / Flasdisk sebelum install atau burning, di sarankan gunakan Rufus/Etchdroid, lalu restart devices ( reboot ) setelah booting awal agar configurasi sempurna
  • Instruksi GPIO:Aktifkan via /system/startup/rc.local ( hapus tanda # pada script gpio untuk aktifkan lalu reboot,jika tidak bekerja beda pin gpio )
  • Perintah Terminal:Ketik xdev untuk XDEV Tools ( auto install + configurasi )
  • Configurasi Bot:Ketik xidz untuk Configurasi Bot Monitoring
  • Qmodem For Modem Rakitan:Qmodem Support Arch : x86-64 | aarch64-generic-armv8 | aarch64-cortex-a53 | aarch64-cortex-a72 | aarch64-cortex-a76 > all Os Version Support ( no tested )
  • ModSdcard Version:Gunakan versi ModSdcard untuk emmc error dan normal ( jangan di install ke EMMC )
  • Informasi !!!:Saya Tidak Bisa Uji coba satu persatu devices karena terlalu banyak firmware dengan berbagai devices berbeda dan jika ada bug/eror di devices tertentu harap maklumi,terimakasih
